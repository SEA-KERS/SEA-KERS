# Team SEA-KERS Website 🚀

Official production website for **Team SEA-KERS** (Builders Collective)—showcasing 20+ global hackathon victories, open-source repositories, engineering roster, and our core mission.

- **Live Production URL**: [https://seakers.vercel.app](https://seakers.vercel.app)
- **Backup Vercel URL**: [https://website-two-red-41.vercel.app](https://website-two-red-41.vercel.app)

---

## 🛠️ Tech Stack & Features

- **Core**: React 19, Vite, JavaScript
- **Styling**: TailwindCSS v4, Technical Brutalism Design System, HSL Theme Tokens
- **Theme**: Light Mode (Default) & Dark Mode (`Kinetic Pulse`) Switcher
- **Interactive Canvas**: HTML5 2D Canvas sampling `Logo White.png` for assembling/disassembling red pixel chevron matrix
- **Analytics**: Integrated `@vercel/analytics`
- **Sections**:
  - **Hero Landing**: Headline (`WE ARE TEAM SEA-KERS`), stat telemetry cards, animated logo matrix.
  - **Challenges Conquered**: 20+ Hackathon victories with modal image galleries, track filtering (`ecell`, `IEEE`, `IISc`, `MSME`, `HAL`), and proof details.
  - **Our Repositories**: Open-source projects with benchmark metrics, GitHub star/fork counters, and spec modals.
  - **Master Minds**: 12-member engineering roster (8 Core Team, 4 Team Members) in a 4-column stacked grid with spotlight modals.
  - **About Us & Our Mission**: Origin lore story, South India travel journey, caret (`^`) symbol meaning, and mission statement banner.

## 💻 Local Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/<your-username>/Team-SEA-KERS-Website.git
   cd Team-SEA-KERS-Website
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run local dev server**:
   ```bash
   npm run dev
   ```
   Open `http://127.0.0.1:5173/` in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```
